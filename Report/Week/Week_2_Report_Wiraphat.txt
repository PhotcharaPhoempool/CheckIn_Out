วันพฤหัสบดีที่ 23 มีนาคม 2569
--------------------------------
(Commit: "Version 3 update" + "update requirement")

วันนี้ทำการ refactor ระบบทั้งหมดจาก face_camera_runner.py ไฟล์เดียว
มาเป็นโครงสร้างแบบ modular ที่แยกหน้าที่ชัดเจนขึ้น โดยสร้างไฟล์ใหม่ 6 ไฟล์:

- camera.py      : ThreadedCamera สำหรับอ่านภาพจากกล้อง
- config.py      : รวมค่า config ทั้งหมดไว้ที่เดียว

- main.py        : Main loop ใหม่ที่ใช้ module ต่าง ๆ
- session_manager.py : จัดการ check-in / check-out
- ui_renderer.py : วาด UI ทั้งหมด (overlay, panel, HUD)

นอกจากนี้ยังอัปเดต requirements.txt ให้ครบ (numpy, opencv-python, insightface,
onnxruntime-gpu, mediapipe, dlib ฯลฯ) และเพิ่ม ForviewSQL.txt สำหรับดู database
